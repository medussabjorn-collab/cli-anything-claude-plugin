## Quick Installation

```bash
# Copy to Claude Code
cp -r C:\Dev\CLI-Anything-Claude-Plugin ~/.claude/plugins/cli-anything

# Restart Claude Code
```

## Usage

```bash
# List all CLIs
cli-hub list

# Get info about a CLI
cli-hub info blender

# Install if not pre-installed
cli-hub install blender

# Launch CLI
cli-hub launch blender
```
